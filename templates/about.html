About Cyber Threat Intelligence Dashboard

Cyber Threat Intelligence Dashboard is a cybersecurity monitoring tool designed to analyze IP addresses, detect potential threats, and visualize security data. The project demonstrates how security analysts can gather intelligence about network activity and detect suspicious behavior using publicly available data sources and threat intelligence techniques.

The system allows users to scan IP addresses, check potential risks, store scan history, generate statistics, and analyze malicious URLs using VirusTotal API. It simulates the workflow used by Security Operations Centers (SOC) to monitor threats and investigate suspicious activity.

Key Features

  • IP Address Threat Detection
  • Country and ISP Intelligence Lookup
  • Risk Score Calculation for IP Addresses
  • Malicious URL Scanner using VirusTotal API
  • Scan History Logging with Database
  • Threat Statistics Dashboard
  • CSV Report Export
  • Admin Panel for User Management
  • Interactive Threat Visualization

Purpose of the Project

The main goal of this project is to demonstrate how cybersecurity tools can be built to collect and analyze threat intelligence. Security analysts often rely on automated dashboards and intelligence platforms to detect suspicious network behavior. This project simulates such a system and helps understand how threat intelligence tools work.
