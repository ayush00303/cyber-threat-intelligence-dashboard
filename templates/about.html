About Cyber Threat Intelligence Dashboard

The Cyber Threat Intelligence Dashboard is a web-based cybersecurity monitoring tool developed using Python and Flask. The main objective of this project is to analyze IP addresses and identify potential cyber threats based on geographic risk analysis.

This system helps security analysts understand suspicious IP activity by collecting threat intelligence data and presenting it through an easy-to-use dashboard interface. The tool is designed to simulate how Security Operations Centers (SOC) monitor network traffic and identify potential malicious activity.

Project Objectives

• Monitor suspicious IP addresses.
• Identify high-risk geographic locations.
• Visualize cyber threat intelligence using dashboards and charts.
• Maintain a scan history for investigation and analysis.

Key Features

• User Authentication System (Register / Login)
• IP Address Threat Analysis
• Risk Score Detection
• Threat Statistics Visualization
• Scan History Logging
• CSV Export for Reports
• Admin Panel for User Monitoring
• Change Password System

Technologies Used

Frontend : HTML, CSS, JavaScript
Backend : Python Flask Framework
Database : SQLite Database
Visualization : Chart.js

Cyber Security Relevance

This project demonstrates how cyber security professionals use threat intelligence tools to analyze network activity. By evaluating IP information and geographic risk levels, security teams can detect suspicious behavior and prevent potential cyber attacks.

The dashboard represents a simplified model of a Security Operations Center (SOC) environment where analysts monitor threats and investigate suspicious IP addresses.
